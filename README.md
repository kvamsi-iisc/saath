# Saath

Planning workspace and marketing site for **Saath**, a trust-first platform for matrimony and
dating. Our own detection models screen every photo for AI generation, deepfakes, face swaps,
heavy editing and stolen images before a profile exists; AI then checks the story for
credibility and matches people on what holds up in real life.

| Path | What it is |
|---|---|
| `site/` | Astro 7 landing page (`cd site && npm install && npm run dev`) |
| `docs/product/` | Feature spec, trust architecture, AI use cases |
| `docs/research/` | Market, competitor, user-complaint, verification-tech and legal research |
| `docs/startup-program/` | Startup programme requirements and application draft |
| `media/` | Design reference and the product-flow film used on the site |

See `CLAUDE.md` for working rules and the hard constraints that shape the product.
